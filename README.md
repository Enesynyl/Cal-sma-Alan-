# Çalışma Alanım

Kaynak dosyaları düzenli tutmak için uygulama sayfa ve özelliklerine göre `src/js` altında ayrılmıştır. Ortak başlangıç ve veritabanı kodu `src/js/core.js` içindedir. Stil dosyaları `src/css` altındadır.

## Geliştirme

`npm run build` komutu kaynak parçalarını tek çalışma çıktısı olan `dist/app.js` ve `dist/app.css` dosyalarında birleştirir; Vercel `dist` klasörünü yayınlar.
